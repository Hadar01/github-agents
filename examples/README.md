# Sample artifacts

Real outputs produced by `github-agent` on real GitHub issues / PRs, committed
verbatim so you can see what the tool actually produces before deciding to
run it. **Nothing here was hand-edited** — these are the raw files the tool
wrote to disk.

## `sample-review-tqec-pr894.md`

A code review of [`tqec/tqec` PR #894](https://github.com/tqec/tqec/pull/894)
("Add conftest.py to increase timeouts for slow tests" — a 10-line, single-file
PR labelled `needs-review`).

Generated by:

```bash
node src/pipeline.js review https://github.com/tqec/tqec/pull/894
# → writes review-report.md (offline; nothing posted to the PR)
# → exits 2 (NEEDS_DISCUSSION)
```

What the review caught (without prompting):
- Marker ordering / override risk when a slow test already carries
  `@pytest.mark.timeout(N)` of its own.
- Implicit `append=True` default — explicit-is-better-than-implicit nudge.
- Silent no-op if `pytest-timeout` is not installed.
- Fragile coupling to a baseline `timeout =` setting that lives outside the
  diff.
- Edge cases around `--timeout` CLI override interaction and the hardcoded
  `SLOW_TEST_TIMEOUT = 300`.
- Missing meta-test (the hook itself isn't tested).

Verdict: `NEEDS_DISCUSSION`, not `REQUEST_CHANGES` — the implementation is
directionally correct, the concerns are about robustness rather than
correctness blockers. The exit code reflects this: CI can gate merges on it
without forcing a hard rewrite.

## `sample-audit-trail-issue-4.md`

End-to-end engineering run on [issue #4](https://github.com/Hadar01/github-agents/issues/4)
of this repo (small request to expose `scripts/verify.js` as an `npm run verify`
script).

Generated by:

```bash
node src/pipeline.js issue https://github.com/Hadar01/github-agents/issues/4 \
  --dry-run --max-cost=1.50
```

Demonstrates the audit-trail format the tool emits for every run:

- **Header** — issue link, branch, pre-fix HEAD with revert command, turns
  used, total cost.
- **Outcome** — one-liner success / give-up / aborted.
- **Safety gates** — verdict, tests-observed-passing, lint-observed-passing.
- **Files touched** — every edited path with edit count and tool used.
- **Test runs** — counts of total / passed / flaky / failed / env-errors.
- **Timeline (condensed)** — one bullet per turn with thought + tool summary.
- **Self-review report** — full reviewer output.
- **Full tool transcript** — collapsed `<details>` for raw debugging.

Cost: **$0.0923** (6 turns). The pipeline blocked the PR because the
self-review verdict was `NEEDS_DISCUSSION` and no passing test run was observed
during the agent session — `--force-pr` would have shipped it, the gate is
designed to make that an explicit, auditable choice.
